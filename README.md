Este é um website fictício para o espaço turístico **Torre de Palma**, com foco em alojamento, restaurante, natureza e venda de cavalos lusitanos.

## 🌐 Estrutura do Projeto

/
├── index.html # Página principal
├── Alojamento.html # Página com detalhes dos quartos
├── Restaurante.html # Página sobre o restaurante
├── Venda.html # Página de venda de cavalos lusitanos
├── Contatos.html # Página de contactos
├── css/
│ └── Index.css # Estilo principal do site
├── img/
│ └── *.jpg, *.png # Imagens usadas no site
├── java/
│ └── Index.js # Scripts JS para interações
│ └── quarto-1.js # Script específico para reservas

## ✨ Funcionalidades

- **Navegação** entre páginas (Home, Alojamento, Restaurante, Contatos, Cavalos)
- **Secção de quartos** com imagens e tipos de acomodação
- **Serviços** como restaurante, SPA, equitação e vinho
- **Venda de cavalos lusitanos** (na página `Venda.html`)
- **Reservas** com cálculo de preço automático (via JavaScript)
- **Design responsivo** com layout simples

## ▶️ Como usar

1. Clona o repositório ou extrai os ficheiros.
2. Abre `index.html` no navegador.
3. Certifica-te de que as pastas `css`, `img` e `java` estão corretamente referenciadas.
4. Podes editar as imagens ou textos para personalizar.
